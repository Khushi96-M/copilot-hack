# Student Study Planner

A beginner-friendly study planner built with plain HTML, CSS, and JavaScript. You can add study tasks, mark them as completed, and delete them when they are no longer needed.

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` directly in a web browser.

For a simple local server, run this command from the project folder if Python is installed:

```bash
python -m http.server
```

Then open <http://localhost:8000> in your browser.
